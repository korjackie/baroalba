상세 필터 패널

검색창(또는 돋보기 버튼) 클릭 시 엔카 스타일 바텀 시트가 올라옴. 홈 화면에서 필터 칩 없애는 대신 여기에 모든 필터 집중.

✓ 홈이 훨씬 깔끔해짐 (필터 칩 제거)
✓ 필터 옵션은 오히려 더 강력해짐
✓ 엔카 UI처럼 "공고보기 N개" 숫자 실시간 업데이트
✓ 토글 조건들 한눈에 설정
– 한 번 더 탭해야 필터 접근 가능

구현 방법

검색바 클릭 시 `openSearchFilter()` 호출 → 기존 모달 패턴으로 패널 슬라이드업. 하단 "공고보기 N개" 숫자는 필터 변경 시마다 Supabase `count` 쿼리로 실시간 업데이트.
