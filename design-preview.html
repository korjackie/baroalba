A+D 조합 홈

A의 Bento 레이아웃에 D의 다크 그래디언트 히어로를 급구 타일에 적용. 필터 칩 제거, 검색창 우측에 돋보기 버튼.

✓ 급구 타일이 히어로처럼 강조됨
✓ 바로모임이 완전히 독립 서비스처럼 보임
✓ 유료/무료 모임 카드 차별화로 업그레이드 동기 유발
✓ 검색창 돋보기 버튼으로 필터 진입점 명확
– 스크롤이 길어짐 (바로모임 섹션 때문)

바로모임 광고 모델 설계

유료 플랜(베이직/프로) 모임은 진한 다크 카드 + "FEATURED" 뱃지로 노출. 무료 플랜은 밝은 텍스트 카드. 카드 순서: 프로 → 베이직 → 무료. 자연스럽게 프리미엄 느낌 차이를 인지시켜 업그레이드 전환 유도.

상세 필터 패널

검색창(또는 돋보기 버튼) 클릭 시 엔카 스타일 바텀 시트가 올라옴. 홈 화면에서 필터 칩 없애는 대신 여기에 모든 필터 집중.

✓ 홈이 훨씬 깔끔해짐 (필터 칩 제거)
✓ 필터 옵션은 오히려 더 강력해짐
✓ 엔카 UI처럼 "공고보기 N개" 숫자 실시간 업데이트
✓ 토글 조건들 한눈에 설정
– 한 번 더 탭해야 필터 접근 가능

구현 방법

검색바 클릭 시 `openSearchFilter()` 호출 → 기존 모달 패턴으로 패널 슬라이드업. 하단 "공고보기 N개" 숫자는 필터 변경 시마다 Supabase `count` 쿼리로 실시간 업데이트.

바로모임 섹션 전개

홈에서는 헤더 + 카드 슬라이더로 궁금증 유발. 클릭 시 전용 패널 열림. 플랜별 노출 방식이 확연히 다름.

✓ PRO FEATURED: 진한 다크 카드 + 대형 노출
✓ BASIC FEATURED: 다른 색 다크 카드 + 중형 노출
✓ 무료: 흰색 리스트 (클릭은 가능, 시각적 차별)
✓ "내 모임 만들기" CTA로 전환 유도

홈 슬라이더 vs 전용 패널

홈 Bento 아래 가로 스크롤 슬라이더는 "티저". 실제 상세는 바로모임 전용 패널에서. 슬라이더 카드를 탭하면 바로 해당 모임 상세 오픈. 이 구조면 홈이 너무 길어지지 않고 바로모임 섹션은 충분히 강조됩니다.

설계 메모

구현 시 참고할 결정 사항

1. 검색 + 필터 진입점

  • · 검색창 클릭 시 키보드가 아니라 필터 패널 바텀시트가 열림
  • · 검색창 안에 텍스트 입력 → 자동완성 (업체명/업종/지역 fuzzy search)
  • · 우측 돋보기 버튼은 항상 필터 패널 열기
  • · "공고보기 N개" 카운트는 Supabase count 쿼리 (head:true) 실시간 반영

2. Bento Grid 데이터 소스

  • · 급구 타일: deadline = 오늘인 공고 count + 상위 2개 샘플
  • · AI PICKS: 기존 AI 추천 로직 그대로 상위 1개
  • · 당일정산: wage_paid=false + same_day_settlement=true 상위 1개
  • · 외국인 환영: nationality_requirement='any' 카운트 표시
  • · 모범파트너: 이번달 완료 건수 상위 1명 (workers 테이블)

3. 바로모임 광고 로직

  • · gatherings 조회 시 host의 플랜 join → 정렬: pro → basic → free
  • · 홈 슬라이더: 최대 6개 (pro 우선, 마감 임박순)
  • · PRO 카드: 다크 보라 배경 + "PRO FEATURED" 뱃지
  • · BASIC 카드: 다크 네이비 배경 + "BASIC FEATURED" 뱃지
  • · FREE 카드: 밝은 연보라 배경 + 뱃지 없음
  • · 추가 수익 모델: 별도 "모임 부스트" 유료 기능 (건당 3,900원으로 3일 최상위 노출) — 장기 계획

4. 구현 순서 (권장)

  1. 홈 Bento 레이아웃 교체 (필터 칩 제거, 급구 다크 타일)
  2. 검색 필터 패널 바텀시트 구현
  3. 바로모임 홈 슬라이더 섹션 + 플랜별 카드 스타일
  4. 각 Bento 타일 실데이터 연결
