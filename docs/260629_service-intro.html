Key Features
핵심 기능

알바생과 업주 모두를 위한 완성된 매칭 생태계

🗺️

위치 기반 지도 탐색

카카오맵에서 내 주변 공고를 마커로 한눈에 확인. GPS 자동 위치, 필터/정렬 지원.

👆

스와이프 공고 탐색

카드 스와이프 UI로 공고를 빠르게 탐색. AI 맞춤 추천으로 내 조건에 맞는 공고 우선 노출.

💬

실시간 1:1 채팅

지원 즉시 업주와 직접 채팅. 이미지 전송, 채팅 인라인 답장, 즐겨찾기 기능 지원.

🔔

스마트 푸시 알림

새 지원자, 수락/거절, 채팅, 맞춤 공고 등록 시 FCM + Web Push로 실시간 알림.

🤖

AI 맞춤 추천

열람·스와이프 이력 기반으로 나에게 맞는 공고를 자동 추천. 관심도 점수 기반 정렬.

🌐

6개국어 다국어 UI

한국어·영어·중국어·일본어·베트남어·러시아어. 외국인 근로자도 불편 없이 사용.

📊

급여계산기 + 수입 달력

주휴수당·실수령액 자동 계산. 월별 수입을 달력으로 한눈에 정리.

🎯

스카우트 & 팔로우

업주가 마음에 드는 알바생에게 먼저 제안. 팔로우한 업체 신규 공고 즉시 알림.

📸

포트폴리오 & 자격서류

알바생 포트폴리오 사진 5장, 자격서류 업로드. 업주 업체사진 5장 등록 지원.

💻

비대면 알바 필터

재택·온라인 가능 공고를 별도 필터로 분리. 비대면 뱃지로 한눈에 구분.

👥

커뮤니티 게시판

업체 후기·정보공유·자유게시판·업주 전용 게시판. 알바생과 업주 통합 커뮤니티.

🎾

레슨 / 과외 / 전문기술 매칭

알바 매칭 외 레슨(스포츠·음악·댄스·미술), 과외(어학·수학·국어), 전문기술(IT·뷰티·크리에이티브) 강사-수강생 매칭까지 통합 운영.

📱

PWA + Android 앱

브라우저에서 바로 사용 (PWA). Google Play Android 앱도 동시 제공.
