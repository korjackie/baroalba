수백 번의 HTML 수정, 캐시 삭제, APK 리빌드도 소용없었던 이유:
JS 코드 자체가 매 실행마다 nav 라벨을 덮어쓰고 있었습니다.

// 버그: navKeys 배열이 구 구조(지도탭→nav_map, 스와이프탭→nav_swipe)를 참조 const navKeys = ['nav_map','nav_swipe','nav_applications','nav_chats','nav_profile']; navLabels.forEach((el, i) => { if (navKeys[i]) el.textContent = t(navKeys[i]); }); // → 홈버튼에 '지도' 출력, 지도버튼에 '스와이프' 출력 // 수정: nav_home 신규 추가, 배열 재정렬 const navKeys = ['nav_home','nav_map','nav_applications','nav_chats','nav_profile']; navLabels.forEach((el, i) => { if (navKeys[i]) el.textContent = t(navKeys[i]); }); // → 홈버튼에 '홈' 출력, 지도버튼에 '지도' 출력
