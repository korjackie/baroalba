두 가지 방식의 만남

여럿이 편한 날엔 바로미팅, 한 사람과 조용히가 좋은 날엔 바로스팟

🤝 바로미팅
정원이 차야 열리는
그룹 소셜 미팅
정원제 · 관리자 승인제 · 익명 캐릭터 채팅

3:3, 4:4처럼 정해진 인원이 다 모이면 그 순간 익명 단체채팅방이 열립니다. 실명 대신 직접 정한 닉네임과 캐릭터로 먼저 대화하고, 마음이 맞으면 그다음에 실사진을 공개해도 늦지 않아요.

신청은 이용권 또는 포인트로 결제되며, 관리자가 신청 내용을 확인한 뒤 정원에 반영합니다. 확정되면 만남까지 남은 시간을 카운트다운·지도가 있는 실시간 추적화면에서 볼 수 있습니다.

이용 안내
·신청 조건 — 바로만남 프로필(직업군·체형·취미)과 대표사진·나이가 있어야 신청 가능
·결제 — 이용권 1회 또는 포인트, 신규가입자 첫 이용 무료체험
·취소 — 채팅방에서 "나가기"로 취소, 노쇼 반복 시 이후 신청 제한
Process
1프로필 등록 마이페이지 기본정보에서 진입
2미팅 신청 이용권 또는 포인트로 결제
3관리자 승인 대기 신청 확인 후 정원 반영
4정원 마감 · 확정 남녀 정원이 모두 차면 확정
5익명 채팅방 입장 닉네임·캐릭터로 대화 시작
6만남 실시간 추적화면으로 장소·시간 확인
📍 바로스팟

1:1로 만나는 자리
1:1 매칭 · 실시간 위치공유 · 상호수락 후 공개

여성 1명과 남성 1명을 매니저가 직접 매칭하는 소개팅입니다. 만나본 뒤 서로 호감을 표시해 둘 다 수락했을 때만 채팅과 이름·사진이 열립니다.

확정 후에는 실시간 위치공유로 서로의 이동 상황을 볼 수 있고, 일정 24시간 전까지는 결제 수단 그대로 전액 환불됩니다.

이용 안내
·신청 방식 — 여성은 매장·일정 선점, 남성은 열린 자리에 신청
·만남 이후 — 상호 호감 표시 후 채팅 오픈, 별점·태그로 상호 평가
·안전 — 채팅방에서 바로 신고 가능
Process
1프로필 등록 직업군·체형·취미·키·MBTI(선택)
2신청 · 선점 여성 선점 → 남성 신청
3매니저 매칭 신청자 중 매니저가 상대 선택
4확정 · 위치공유 매칭 확정 시 실시간 위치공유 오픈
5만남 배정된 매장에서 식사
6호감 표시 → 채팅 상호 수락 시 이름·사진 공개
7상호 평가 별점·태그로 평가, 신뢰 지표 반영
