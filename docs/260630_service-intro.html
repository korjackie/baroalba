Key Features
핵심 기능

알바 매칭 · 커뮤니티 · 레슨 · 모임을 하나로 통합한 완성된 생활 플랫폼

🗺️

지도 기반 실시간 탐색

카카오맵 SDK로 내 주변 공고를 마커로 즉시 확인. GPS 자동 위치, 필터/정렬, 지도 스와이프 탐색 지원.

👆

스와이프 공고 탐색

카드 스와이프 UI로 공고를 빠르게 탐색. 급구·AI추천·당일정산·외국인환영·모범파트너 맞춤 섹션 제공.

👥

팀모집 공고

N명 모집 진행률 바와 "N자리 남음" 표시. 픽업장소·초보환영·식사포함 배지로 몽골 커뮤니티 맞춤 공고 지원.

📋

공고 전체 생애주기 관리

공고 등록·수정·복사·마감·재오픈·삭제. on-air 토글로 구인 중 실시간 표시. 국적 조건 필터(국적무관/한국인만/한국어필수/외국인환영).

✅

지원자 풀 처리

알바생 지원·취소. 업주 지원자 검토·합격·탈락·완료·노쇼 처리. 전체 워크플로를 한 화면에서.

📄

전자 근로계약서

채용 확정 시 근로계약서 자동 생성 및 인쇄. 법적 요건을 갖춘 서식으로 분쟁 예방.

🏅

신뢰점수 시스템

알바생 0~99점 신뢰점수. 평점·리뷰·노쇼 이력을 종합 반영. 업주가 신뢰도를 한눈에 파악.

⭐

양방향 리뷰 + 답글

근무 완료 후 업주↔알바생 상호 평가. 리뷰 답글 기능으로 억울한 평가에 소명 가능.

🪪

비자/외국인 서류 업로드

외국인 근로자 비자·체류자격 서류를 앱 내에서 직접 업로드. 업주 열람 및 채용 적합성 확인.

💬

실시간 1:1 채팅

지원 즉시 업주와 직접 채팅. 이미지 전송·인라인 답장·즐겨찾기 지원. 단골 알바생 구독 시 새 공고 알림.

🔔

FCM 푸시 알림

Web Push + Android FCM으로 새 지원자·수락/거절·채팅·맞춤 공고 실시간 알림.

📍

실시간 위치 공유

채팅 내 실시간 위치 공유. 출퇴근 확인, 픽업 장소 안내 등 현장 커뮤니케이션 강화.

📰

커뮤니티 게시판

글·댓글·이미지 지원. 업체 후기·정보공유·자유게시판·업주 전용 게시판. 알바생-업주 통합 커뮤니티.

🎾

레슨 / 과외 / 전문기술 매칭

스포츠·음악·댄스·미술 레슨, 어학·수학 과외, IT·뷰티·크리에이티브 전문기술 강사-수강생 매칭.

📊

급여계산기 + 수입 달력

주휴수당·실수령액 자동 계산. 월별 수입을 달력으로 한눈에 정리. 알바생 재무관리 지원.

📱

PWA + Android 동시 지원

브라우저에서 바로 사용 가능한 PWA. Google Play Android 앱 동시 제공. 설치 없이 즉시 접속.

참가 신청 (승인제)

참가 신청 → 개설자 승인 구조. 불특정 다수의 난입 없이 원하는 멤버만 선별.

공개 / 비공개 모임

공개 모임은 누구나 탐색·신청 가능. 비공개 모임은 초대 딥링크로만 입장.

💬

단체 채팅

참가 승인 즉시 전용 단체 채팅방 생성. 공지·이미지·위치 공유 지원.

🔗

초대 딥링크

카카오톡·문자로 링크 공유 → 클릭 즉시 모임 상세 페이지로 이동. 마찰 없는 초대.

📌

내 모임 대시보드

개설한 모임과 참가한 모임을 한 화면에서 관리. 멤버 현황·채팅·일정 통합 확인.
