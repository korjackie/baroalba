레슨/과외 채팅 DDL — application_id NOT NULL 해제
DDLBUG FIX v330 · messages 테이블

레슨 문의 채팅에서 메시지 발송 시 "messages.application_id NOT NULL constraint" 오류 발생.

레슨 채팅은 application_id가 없고 inquiry_id를 사용하는 구조이므로 NOT NULL 제약 조건 제거 필요.

-- 기존: application_id NOT NULL → 레슨 채팅 발송 불가 -- DDL 수정 (Supabase 콘솔 실행 완료) ALTER TABLE messages ALTER COLUMN application_id DROP NOT NULL;

외국인환영 바텀시트 드래그 애니메이션 추가
UX FIX v331 · setupBottomSheetDrags

외국인환영 언어 선택 시트를 드래그로 내리면 즉시 닫히고, 중간 위치에서 손을 떼면 위치 고정되지 않던 문제. touchmove에서 translateY 처리가 없었음.

// 이전: touchmove 없이 touchend만 처리 → 드래그 중 시트 위치 변화 없음 // 수정: touchmove에서 translateY 실시간 반영 document.addEventListener('touchmove', e => { if (!_bshCur || !_bshSheet) return; const dy = Math.max(0, e.touches[0].clientY - _bshSy); _bshSheet.style.transform = `translateY(${dy}px)`; // 실시간 위치 반영 }, { passive: true }); // touchend: 80px 이상 내렸으면 닫기 애니메이션 후 close() document.addEventListener('touchend', e => { const dy = e.changedTouches[0].clientY - _bshSy; if (dy > 80) { _bshSheet.style.transition = 'transform 0.15s ease'; _bshSheet.style.transform = 'translateY(100%)'; setTimeout(() => { _bshCur?.close(); }, 140); } else { _bshSheet.style.transition = 'transform 0.2s ease'; _bshSheet.style.transform = ''; // 원위치 스냅백 } }, { passive: true });

홈탭 진입 또는 공고 등록 폼 닫을 때 FAB이 홈화면에 뜨는 문제. 2가지 원인이 있었음.

⚡
3종 숏컷 아이콘 — 인플레이스 홈 필터로 통일
UXNEW v332 · 홈 숏컷

기존: AI추천·외국인환영은 바텀시트 패널로 진입 → 화면 전환 후 다시 홈으로 돌아와야 했음.
개선: 높은시급과 동일하게 홈 화면 내에서 검색결과 영역만 교체하는 인플레이스 방식으로 통일.

숏컷 이전 방식 변경 후
💰 높은시급 인플레이스 필터 동일 유지
🤖 AI추천 RANK 바텀시트 패널 → openAIFilter() 인플레이스
🌏 외국인환영 언어 선택 바텀시트 → showForeignerInHome() 인플레이스
🎓 레슨/과외 전체 패널 (유지) 동일 유지
// AI 추천 — 행동 이력(로컬스토리지) 기반 개인화 공고 목록 function openAIFilter() { const prefs = JSON.parse(localStorage.getItem(_aiKey()) || 'null'); if (!prefs || prefs.totalSignals < 3) { // 데이터 부족: "공고를 더 둘러볼수록 추천이 시작돼요" 안내 return; } const scored = (jobs||[]) .filter(j => j.status === 'open' || j.status === 'urgent') .map(j => ({ job: j, score: _aiScoreJob(j, prefs) })) .filter(x => x.score > 0) .sort((a, b) => b.score - a.score) .map(x => x.job); _renderHomeSearchList(scored); } // 외국인환영 — nationality_requirement === 'foreigner_welcome' 필터 function showForeignerInHome() { const filtered = (jobs||[]).filter(j => (j.status==='open'||j.status==='urgent') && j.nationality_requirement === 'foreigner_welcome' ); _renderHomeSearchList(filtered); }
