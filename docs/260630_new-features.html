🏠 홈 UX

바로알바 탭 = 목적별
홈화면으로 전환

기존 피드 나열 방식을 벗어나, 사용자가 원하는 상황(급구·AI추천·외국인환영 등)에 맞게 바로 진입할 수 있는 홈탭으로 전환합니다.

1
통합 검색바
직종·지역·업체명을 한 곳에서 검색. 홈화면 최상단 고정.
2
급구 섹션
마감 임박 공고 카루셀. 실시간 N개 카운트 표시.
3
AI추천 / 당일정산 / 외국인환영 섹션
이력 기반 AI 추천, 당일 정산 필터, 비자 무관 공고를 별도 섹션으로 큐레이션.
4
모범파트너 섹션
인증 업체 공고를 별도 배지와 함께 노출. 신뢰 지표 강화.
💡 홈탭은 기존 피드 탭을 대체합니다. 피드는 검색·섹션을 통해 진입하는 방식으로 변경됩니다.

🌐 국적 필터

업주는 조건 설정,
외국인 유저는 자동 필터링

불필요한 지원-거절 사이클을 줄입니다. 업주가 설정한 국적 조건에 따라 외국인 유저의 피드와 지원 자체를 자동으로 제어합니다.

1
공고 등록 시 4단계 선택
국적무관 / 한국인만 / 한국어필수 / 외국인환영. 기본값은 국적무관.
2
외국인 유저 피드 자동 필터
nationality 필드가 비한국인인 유저에게 "한국인만" 공고는 피드에서 제외.
3
한국인only 공고 — 지원 버튼 차단
외국인 유저가 상세 페이지 진입 시 지원 버튼 비활성화 + 안내 메시지 표시.
4
외국인환영 공고 — 배지 자동 표시
카드와 상세에 "🌏 외국인환영" 초록 배지 노출. 외국인 피드에서 상위 노출.
⚙️ DB: job_postings 테이블에 nationality_filter TEXT DEFAULT 'any' 컬럼 추가 필요 (any / korean_only / korean_required / foreigner_welcome).

확정 인원이 모집 인원에 달하면 배지가 "✅ 모집완료"로 변경, 지원 버튼 비활성화.

2
Phase 2 — Supabase Realtime 단체채팅
승인된 참가자+주최자만 입장 가능한 단체채팅방. Supabase Realtime Broadcast 기반.

4
