신뢰점수 신규 유저 75점 인플레이션 수정
BUG calcBakalbaScore 로직 수정
후기가 없어도 rating 기본값을 3.0으로 설정해 신규 유저가 75점을 받는 버그. 후기 0건이면 rating 기여 0으로 처리하고 기본점수를 60→40으로 낮춤.
// 이전: 후기 없으면 3.0 기본 → 60 + 15 = 75점 const rating = parseFloat(w?.rating) || 3.0; score = 60 + (rating/5)*25 + reviews*0.5 - noshow*7 // 수정: 후기 없으면 rating 기여 0 const rating = reviews > 0 ? (parseFloat(w?.rating) || 0) : 0; score = 40 + (rating/5)*35 + reviews*1.5 - noshow*8
