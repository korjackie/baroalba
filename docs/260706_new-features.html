Bug Fixes
🪲 버그 수정 4건
신뢰점수 인플레이션 · 급여확인 스피너 · 외국인허브 타이밍 · 바로만남 뒤로가기.
BUG
신뢰점수 신규 유저 인플레이션 수정
원인: rating || 3.0 기본값으로 리뷰 없어도 75점 출력. 수정: 리뷰 0건 시 rating 기여 0. 기본점수 60→40. 마이페이지 통계에서 review_count=0이면 숫자 대신 '-' 표시.
- const rating = parseFloat(w?.rating) || 3.0; + const rating = reviews > 0 ? (parseFloat(w?.rating) || 0) : 0; - const score = Math.round(60 + ...); + const score = Math.round(40 + ...);
BUG
급여수령확인 무한 스피너 수정
재호출 시 spinner 리셋 누락 수정. Promise.race로 8초 타임아웃 추가. status 필터에서 미사용 'done' 제거.
BUG
외국인허브 전환 타이밍 (200ms→320ms)
CSS 전환(280ms)보다 짧은 setTimeout(200ms)으로 패널이 겹치던 버그. 320ms로 연장.
BUG
바로만남 패널 Android 뒤로가기 미작동
popstate 핸들러에서 mannnam-panel 누락. 이번 릴리즈에서 수정 완료.
