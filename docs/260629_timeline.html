Improvement Planning

개선안 기획

실제 사용 시 불편한 지점, 경쟁 앱 대비 부족한 부분

⭐

리뷰 답글 기능

업주가 알바생 리뷰에 답변 가능하도록. 신뢰도 향상 + 분쟁 방지.

WHY: 리뷰만 있고 답글 없으면 업주 억울한 경우 대응 불가
📊

업주 통계 대시보드

공고별 지원자 수, 합격률, 채팅 전환율, 조회수 트렌드 그래프 제공.

WHY: 업주가 어떤 공고가 잘 되는지 데이터 기반으로 판단 가능
📅

알바생 일정 관리

수락된 공고를 캘린더에 자동 등록. 출퇴근 일정 관리 및 중복 방지.

WHY: 수입 달력은 있지만 예정 일정 관리 기능 없음
🔍

상세 검색 필터 강화

스킬 태그 매칭, 학력/경력 필터, 언어 우대 + 비대면 복합 필터 지원.

WHY: 현재 필터가 시급·거리·근무형태 위주로 제한적

🔧 기능 완성도 개선 중간

구현됐지만 미완성인 기능들

💬

커뮤니티 수정/삭제 + 익명

내 글·댓글 편집 버튼, 댓글 익명 토글(현재 false 고정).

WHY: 기본 커뮤니티 기능인데 미구현 상태
🎯

AI 추천 피드백 루프

지원·합격·완주 이력을 추천 알고리즘에 반영. 시간이 지날수록 정확도 향상.

WHY: 현재 AI 추천은 열람/스와이프만 반영, 실제 지원 결과 미반영
⏰

공고 자동 마감 + 재게시

종료일 지난 공고 자동 비활성화. 업주 클릭 한 번으로 공고 재게시.

WHY: 만료 공고가 계속 노출되면 알바생 신뢰도 하락
📩

알림 히스토리 + 읽음 표시

받은 알림 목록 화면. 현재 푸시만 있고 앱 내 조회 불가.

WHY: 알림 놓쳤을 때 재확인 경로 없음

🚀 신규 기능 기획 전략적

경쟁 우위를 위한 새로운 기능 아이디어

🔒

에스크로 알바비 보장

업주가 알바비 선입금 → 근무 확인 후 지급. 임금 체불 방지 + 알바생 신뢰.

WHY: P2P 플랫폼 최대 리스크인 임금 미지급 문제 근본 해결
📜

전자계약서 자동 생성

수락 시 근로계약서 자동 생성 → 알바생·업주 전자서명 → PDF 저장.

WHY: 단기 알바도 계약서 있으면 법적 보호 + 플랫폼 차별화
📍

실시간 위치 공유 (프리미엄)

근무 중 알바생 위치를 업주가 실시간 확인. 현장 관리형 업종 특화.

WHY: 배달·이벤트 스태프 등 현장 관리 필요한 업종 수요
🏅

알바생 신용점수 고도화

노쇼·취소·완주·평점을 종합한 '바로알바 신뢰 점수'. 숫자로 표시.

WHY: 업주 입장에서 알바생 신뢰도를 객관적으로 판단 가능
🤝

단골 알바생 구독 시스템

업주가 자주 쓰는 알바생을 '단골'로 등록 → 공고 올리면 단골에게 먼저 알림.

WHY: 재고용률 높은 알바생·업주 관계를 플랫폼이 강화
🎓

알바 교육 콘텐츠

서비스직 매너, 카페 바리스타 기초 등 단기 교육 영상 연계. 수료 뱃지 발급.

WHY: 알바생 스펙 강화 + 플랫폼 체류 시간 증가
