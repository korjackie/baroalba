Android App
Android 하이브리드 구조

WebView 기반으로 웹 코드를 100% 재사용하면서 네이티브 기능을 추가 연동

📡 AndroidBridge (JS ↔ Native)

// JS에서 호출 AndroidBridge.share(title, text, url); AndroidBridge.showKeyboard(); // SHOW_FORCED AndroidBridge.hideKeyboard(); AndroidBridge.setScrollKbGuard(true); AndroidBridge.saveAuthToken(jwt); // Native → JS 콜백 window._onFCMToken(token); window._onNativeKbChange(heightDp); // CSS 변수 주입 (safeArea) --sat : status bar height (dp) --sab : navigation bar height (dp)

🎨 스플래시 해결 구조 (v23)

// 1. 투명 아이콘 (OS 강제 렌더링 제거) ic_splash_icon.xml → 빈 벡터 // 2. SplashScreen 즉시 dismiss SplashScreen.installSplashScreen(this) .setKeepOnScreenCondition(() -> false); // 3. WebView 배경색 (흰색 플래시 방지) webView.setBackgroundColor( Color.parseColor("#C8102E")); // 4. login.html 웹 스플래시 (4초 최소) _afterSplash(fn) → 경과시간 계산 후 전환

// 네이티브 IME 높이 측정 → JS 전달 ViewCompat.setOnApplyWindowInsetsListener( webView, (v, insets) -> { int imeHeight = imeVisible ? imeInsets.bottom - bars.bottom : 0; applyKbHeight(imeHeight); // JS 콜백 return CONSUMED; } ); // 채팅 키보드 강제 유지 (SHOW_FORCED) imm.showSoftInput(webView, InputMethodManager.SHOW_FORCED);

Technical Highlights
기술적 도전과 해결
01

프레임워크 없이 단일 HTML 파일로 전체 앱 구현

React/Vue 없이 순수 Vanilla JS로 지도·스와이프·채팅·마이페이지 등 전체 기능을 바로알바.html 단일 파일에 구현. 배포가 간단하고 CDN 캐싱 효율이 높음. 모든 패널은 position:fixed + transform으로 SPA 수준의 전환 구현.

Single File Architecture
02

RLS만으로 서버 코드 없는 보안 데이터 접근

Supabase Row Level Security로 서버리스 함수 없이 완전한 접근 제어. workers/businesses는 kakao_uid = auth.uid() UUID 직접 비교. 커뮤니티 글/댓글은 worker_id OR business_id 존재 검증으로 알바생·업주 통합 처리.

Zero Server Code for CRUD
03

Android WebView 키보드 3중 방어 시스템

Android IME 높이를 ViewCompat.setOnApplyWindowInsetsListener로 측정 → JS _onNativeKbChange 콜백으로 전달 → CSS translateY 조정. 채팅 전송 시 SHOW_FORCED로 키보드 강제 유지 + scrollKbGuard로 스크롤 닫힘 방지 + 1.5초 안전장치 자동 해제.

Triple Keyboard Defense
04

이중 Push 알림 시스템 (VAPID + FCM)

브라우저/PWA는 VAPID 기반 Web Push(Vercel 서버리스), Android는 FCM 네이티브 토큰. FCM 토큰은 페이지 로드 전 수신될 수 있어 latestFCMToken에 보관 후 onPageFinished에서 재전달하는 타이밍 이중화 구조.

Dual Push Architecture
05

6개국어 번역 엔진 — shared-lang.js

TRANSLATIONS 객체 + data-i18n HTML 속성으로 applyLang() 한 번 호출로 전체 UI 자동 번역. 이동수단/강점/근무형태는 별도 레이블 객체로 칩 UI 자동 처리. 두 앱(바로알바.html + owner.html)이 동일 파일 공유.

Shared i18n Engine
06

Android 스플래시 완전 해결 (3단계)

①ic_splash_icon.xml 투명 벡터로 OS 강제 아이콘 렌더링 제거 → ②SplashScreen.installSplashScreen 즉시 dismiss → ③WebView setBackgroundColor(#C8102E)로 흰색 플래시 방지. 이후 login.html 웹 스플래시가 4초 최소 보장(_afterSplash 헬퍼).
