UX 개선

기능 완성도
레슨/과외 고도화

신뢰점수 시각화
신뢰점수 상세 내역 보기. 점수 올리는 방법 가이드. 업주 대시보드 신뢰점수 히스토그램.

공고 AI 작성 도우미
업종/시급/위치 입력하면 AI가 매력적인 공고 문구 자동 생성. 다국어 공고 자동 번역.
