Feature 01

알바생 신뢰점수 고도화

단순 별점을 넘어 노쇼·리뷰·완료 이력을 종합한 숫자 점수로 알바생 신뢰도를 객관화합니다.

★ 4.6

🏅 신뢰 지표

숫자 하나로 알바생의
신뢰도를 즉시 파악

기존 별점만으로는 판단이 어려웠습니다. 노쇼·취소 이력, 리뷰 수, 평점을 종합해 0~99점의 신뢰점수로 변환합니다.

1
기본 60점에서 시작
모든 알바생의 시작 점수. 최소 2건의 완료 이력이 있어야 표시됩니다.
2
평점 최대 +25점
5점 만점 평점을 비율로 환산. 5.0점이면 +25, 4.0점이면 +20점.
3
노쇼 1회당 -7점 패널티
노쇼 이력이 있으면 점수가 크게 하락. 최대 10회까지 반영.
💡 지원자 카드에 "신뢰 N점" 뱃지로 즉시 확인 가능. 신규 알바생(2건 미만)은 뱃지 미표시.

Feature 02

단골 알바생 우선 알림

업주가 단골로 등록한 알바생에게 새 공고를 우선 발송합니다. 재고용률이 높은 관계를 플랫폼이 강화합니다.

발송 순서
⭐
1순위 — 단골 알바생
[단골 업체] 태그 포함. 업주가 ♥ 등록한 알바생에게 가장 먼저 발송.
🔔
2순위 — 팔로워 알바생
업체를 팔로우한 알바생에게 새 공고 알림 발송.
📢
3순위 — 맞춤 매칭 알바생
카테고리·최소시급 조건이 맞는 알바생 최대 50명에게 발송.
📱 단골 알바생이 받는 메시지
⭐ 멀티무브 카페
[단골 업체] 홀 서빙 · 13,000원 새 공고가 올라왔어요
🤝 재고용 강화

믿을 수 있는 알바생과
더 자주 함께

한번 좋았던 알바생이 다음에도 오게 하려면 빠른 알림이 중요합니다. 단골 알바생이 공고를 가장 먼저 받아 지원 가능성을 높입니다.

BEFORE
  • 😐 단골 알바생도 일반 알바생과 동일한 알림
  • ⏰ 공고 뜨는 걸 직접 확인해야 지원 가능
  • ❌ 빠른 마감 시 단골도 놓칠 수 있음
AFTER
  • ⭐ [단골 업체] 태그 우선 발송
  • 🔔 공고 등록 즉시 자동 알림
  • ✅ 재고용 가능성 극대화

Feature 03

전자계약서 자동 생성

지원 수락 버튼 하나로 근로계약서가 자동 생성됩니다. 별도 작성 없이 법적 계약 관계를 명확하게 합니다.

근 로 계 약 서
바로알바 플랫폼 자동 생성

멀티무브 카페(이하 "사용자")와 김민준(이하 "근로자")는 다음과 같이 근로계약을 체결합니다.

직무홀 서빙
근무일시2026년 6월 30일 오전 10:00
근무지서울 마포구 홍대입구로 12
임금13,000원/시간
사용자멀티무브 카페 (010-1234-5678)
근로자김민준 (010-9876-5432)
① 임금은 근무 종료 후 당일 또는 익일 지급을 원칙으로 한다.
② 근로자는 계약된 시간을 성실히 이행한다.
📜 법적 보호

클릭 한 번으로
계약서가 자동 완성

단기 알바도 계약서가 있으면 임금 분쟁을 방지합니다. 지원 수락 시 자동 팝업으로 즉시 확인하고 출력까지 가능합니다.

1
업주가 지원 수락
"최종 확정" 버튼을 누르면 0.5초 후 계약서 팝업 자동 표시.
2
공고·지원서 데이터로 자동 기입
직무명, 근무일시, 시급, 주소, 업체·알바생 연락처를 모두 자동 채움.
3
출력/저장으로 기록 보관
새 창에서 인쇄 다이얼로그 실행. PDF로 저장도 가능.
⚖️ 근로기준법상 단기 알바도 근로계약서 작성 의무. 자동 생성으로 업주 법적 부담도 해소.

Feature 04

실시간 위치 공유

확정된 알바생이 위치 공유를 시작하면 업주가 실시간으로 현재 위치를 확인할 수 있습니다. 배달·이벤트 스태프 등 현장 관리 업종에 특화.

알바생이 어디 있는지
실시간으로 확인

전화나 문자 없이 현재 위치를 바로 확인할 수 있습니다. 알바생이 공유를 시작해야만 위치가 전송되며, 언제든 중지 가능합니다.

1
알바생 — 위치 공유 시작
확정된 공고 카드의 "📍 위치 공유 시작" 버튼 탭. GPS 권한 요청 후 10초 간격 전송.
2
Supabase Realtime으로 실시간 전달
별도 서버 없이 Supabase Broadcast 채널로 위도·경도 즉시 전달.
3
업주 — 지도 링크로 확인
카카오맵 링크로 현재 위치 즉시 확인. 직접 지도 탐색도 가능.
🔒 알바생이 공유를 시작해야만 위치가 전송됩니다. 강제 추적 기능은 없습니다.
