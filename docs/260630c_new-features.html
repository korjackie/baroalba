뒤로가기 후 빈 화면 — popstate 미처리
BUG FIX v312 · Android 뒤로가기 내비게이션

외국인 필터 → 공고 상세 진입 → Android 뒤로가기 → 빈 화면(지도탭)으로 이동하는 버그.

원인: popstate 핸들러가 .full-panel.show만 체크. 공고 상세(detail-overlay)는 .open 클래스를 사용하므로 감지 불가 → 브라우저 기본 히스토리 pop 발생.

  • 1
    detail-overlay.classList.contains('open') → 상세 닫기
  • 2
    panel-foreigner-lang.style.display === 'block' → 언어 패널 닫기
  • 3
    panel-rank.style.display === 'block' → RANK 패널 닫기
  • 4
    기존 .full-panel.show 처리 (유지)

각 케이스 처리 후 history.pushState로 히스토리 기준점 재설정.
