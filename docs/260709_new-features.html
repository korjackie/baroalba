BUG
바로미팅 신청 — 실제로는 아무것도 저장 안 되던 반쪽 구현
포인트 잔액만 확인하고 실제 차감도, gathering_applications 저장도 없이 토스트만 뜨던 코드. 참가 확정 시 성별 인원 카운터(baromeeting_male_cur/female_cur)를 실제로 증가시키고, 이용권이 있으면 이용권으로 우선 차감(바로스팟과 풀 공유), 없으면 1회권과 동일 가격의 포인트를 실제로 차감하도록 완성.
NEW
정원 마감 시 익명 단체채팅방 자동 개설
남녀 정원이 모두 차면 카드에 "💬 익명 단체채팅방 입장" 버튼 노출. 실명 대신 본인이 직접 정한 익명 닉네임(최대 12자) 사용, 프로필 사진 공개 여부도 옵션으로 선택 가능(기본 비공개). 기존 바로모임 채팅 인프라(gathering_chats) 재사용.
BUG
공고 복사/재등록 시 재지원 차단되던 문제
지원취소·재등록 시 기존 지원자를 DELETE하던 로직이 RLS상 조용히 0건 처리됐을 가능성. cancelled 상태로 전환하는 방식으로 바꿔, 이미 고친 재지원 로직(취소 상태 재지원 허용)을 그대로 타도록 통일.
UX
업주용 "앱 언어" 설정 화면 신설
shared-lang.js는 업주용 요소 ID까지 이미 준비돼 있었지만 정작 HTML 화면이 없어서 메뉴 자체가 없던 상태. 알바생 쪽과 동일한 화면을 업체 설정에 추가(신규 로직 없이 기존 함수 재사용).
Bug Fixes

BUG

18세 미만 제한 공고인데도 카드가 지원 성공처럼 날아가던 버그. 번개지원과 동일하게 카드를 날리기 전에 먼저 자격 검사하도록 순서 변경.

버튼이 인덱스만 리셋하고 목록을 재구성하지 않아 이미 본 공고가 그대로 반복 노출되던 문제. initSwipe() 재호출로 수정.
BUG
홈 화면 필터 복귀 안 되는 문제
외국인환영 등 필터 적용 후 다른 탭 갔다 오면 기본 홈 화면이 안 나오던 버그. 탭 전환 시 필터 결과 화면이 열려 있으면 자동 초기화.
BUG
MOIM_PLAN_LIMITS 키 오타
standard→basic. 베이직 결제자가 월 10개가 아닌 무료와 동일하게 1개로 제한되던 버그.
BUG
businesses.plan 로그인 시 미로드
결제 직후에만 메모리에 반영되고 새로고침/재로그인 시 항상 무료로 리셋되던 문제. 로그인 시 실제 plan 값으로 복원.
BUG
지도 진입 시 내 위치 마커 자동 미표시
지도 탭을 나갔다 다시 들어오면 "내 위치 보기"를 눌러야만 마커가 다시 뜨던 문제. 탭 재진입 시 자동으로 위치 추적 재시작.
