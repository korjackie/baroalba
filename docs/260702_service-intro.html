PROBLEM & SOLUTION

기존 단기 알바 시장의 문제를
바로알바가 해결합니다

기존 문제점
급여 지급이 며칠씩 걸려 생활 자금 부담
공고가 텍스트 목록뿐 — 위치 파악이 어려움
외국인이 한국어 공고를 읽기 어렵고 지원 불가
지원 후 합격 여부를 일일이 확인해야 함
업주가 지원자를 검증할 수단 없음
비자별 취업 가능 업종 안내 없음
노쇼 알바생에 대한 대처 방법 없음
레슨·과외 매칭 특화 플랫폼 부재
바로알바 해결
당일정산: 근무 완료 시 즉시 입금
지도 탐색: 현재 위치 기반 반경 내 공고 시각화
7개국어 지원: 한국어·영어·중국어·일본어·베트남어·러시아어·몽골어
실시간 알림: FCM 푸시로 합격 즉시 알림
신뢰점수 시스템: 0~99점 기반 알바생 검증
비자 필터: 비자별 취업 가능 업종 자동 안내
신뢰점수 차감: 노쇼 이력 자동 반영
레슨/과외 전용 매칭: 문의채팅·시급협의·리뷰
FEATURES

핵심 기능

알바생, 업주 모두를 위한 완성도 높은 기능들입니다.

알바생
💰
당일 정산
일한 당일 바로 입금. 기다림 없는 알바 플랫폼의 새 기준. 업주 에스크로 선납 → 당일 자동 이체.
공통
🗺️
지도 탐색
현재 위치 기반으로 걸어갈 수 있는 공고를 지도에서 바로 발견. 알바 마커 ↔ 모임 마커 토글.
알바생
⚡
번개지원 (스와이프)
틴더처럼 스와이프로 빠른 지원. 번개지원으로 최우선 매칭. 지도 하단 플로팅 버튼으로 진입.
공통
🏠
홈 피드 (B3 + 인플레이스 필터)
숏컷 4개(높은시급·AI추천·외국인환영·레슨과외) 클릭 시 화면 이동 없이 홈 피드 내 즉시 필터 적용.
공통
🤖
AI 추천
클릭/지원/찜 행동 이력 기반 개인화 공고 추천. 데이터가 쌓일수록 정확도 향상. 홈 숏컷으로 바로 진입.
공통
💬
실시간 채팅
업주↔알바생 1:1 채팅. Supabase Realtime 기반. FCM 푸시 알림으로 메시지 수신 즉시 알림.
알바생
⭐
신뢰점수 시스템
0~99점 신뢰점수. 평점·리뷰·노쇼 이력 자동 계산. 업주에게 색상 코드로 시각화 (🟢 80+ / 🟡 60+ / 🔴 60미만).
업주
📋
공고 관리
3분이면 공고 등록 완료. 마감일 자동 마감. 시급 입력 시 하루 예상 급여 실시간 미리보기.
업주
👥
Staff 관리 패널
고용 이력 알바생 리스트. 재고용 / 블랙리스트 / 메시지. 신뢰점수 기반 색상 표시.
공통
📝
양방향 리뷰 + 답글
업주↔알바생 상호 평가. 리뷰 답글(양방향). 신뢰점수 자동 반영.
알바생
🌍
외국인 특화
비자별 취업 가능 업종 자동 필터. 픽업/초보환영/식사포함 배지. 7개 언어 권리 가이드.
공통
🎓
레슨/과외 매칭
언어·악기·스포츠·예술 등 전문기술 레슨 매칭. 문의 채팅으로 시급 협의. 레슨 리뷰 시스템 연동.
업주
💌
단골 우선 알림
지정 단골 알바생에게 새 공고 등록 시 최우선 알림 발송. 프로 플랜 강화 혜택.
공통
📍
실시간 위치 공유
당일 알바 중 업주-알바생 실시간 위치 공유. Supabase Realtime location:{appId} 채널.
TRUST & SAFETY

신뢰 & 안전 시스템

플랫폼의 신뢰를 지키는 4가지 핵심 장치입니다.

⭐
0~99
신뢰점수
평점, 리뷰 수, 노쇼 이력, 근무 완료 횟수 기반 자동 계산. 업주에게 색상으로 시각화.
🚫
차감
노쇼 패널티
무단 결근 시 신뢰점수 대폭 차감. 반복 노쇼 시 플랫폼 이용 제한. 업주 블랙리스트 가능.
📝
양방향
상호 리뷰 + 답글
업주→알바생, 알바생→업주 상호 평가. 양방향 답글 기능. 이력 공개로 투명한 거래 환경.
📋
법적
전자계약서
근로계약서 자동 생성. 근로기준법 조항 포함. 7개 언어 지원. 법적 효력 있는 전자서명.
BAROMOIM

바로모임 — 알바를 넘어 커뮤니티로

홈탭에서 바로 진입하는 소셜 모임 서비스. 스포츠·취미·파티·카풀까지.

🎉
모임 개설 & 참가
스포츠/취미/소셜/파티/카풀/기타 6개 카테고리. 공개 모임은 바로 신청. 비공개는 초대 딥링크로만 참가. 참가비 각자분담 옵션.
🔒
공개 / 비공개 모임
비공개 모임은 딥링크 공유 시에만 참가 신청 가능. 카카오톡 공유 (모임명/날짜/장소/인원 포맷). 초대 전용 멤버십.
💬
Realtime 단체채팅
승인된 참가자 + 주최자만 입장 가능한 단체채팅방. Supabase Realtime Broadcast 기반.
🗺️
지도에서 모임 탐색
지도 탭에서 알바 마커 ↔ 모임 마커 토글. 장소 기반으로 주변 모임 발견.
📊
주최자 대시보드
참가 신청 목록 관리. 개별 승인/거절. 참가 진행률 바 표시. 모임 인원 현황 실시간 업데이트.
🔗
딥링크 공유
카카오 공유 + 링크 복사. baroalba:// 딥링크 → 앱 직접 진입 or 웹 랜딩페이지.
